# 军团海报背景模板与资料增强设计

## 背景与目标

现有海报工作台已经支持招募、军团介绍和活动宣传三种内容版式，但背景视觉较为单一，军团资料也缺少可用于快速识别的类型、区域和福利信息。本阶段在不改变现有审核、发布和权限模型的前提下：

- 将海报背景从内容版式中解耦，允许用户在编辑器中选择背景并实时预览。
- 增加军团类型标签（海盗、主权）、区域标签（高安、低安、00 地区）、结构化福利列表，以及继续使用现有联盟归属字段。
- 让新增字段同时出现在编辑表单、公开详情、目录卡片和海报中。
- 保持旧版本 JSON 草稿和已发布版本可读取，不要求覆盖线上业务库或重建历史数据。

## 已确认的视觉方向

背景模板先提供六种，均由 Canvas 本地绘制，不依赖远程图片或第三方素材，保证导出稳定、可离线预览：

1. **深空星云**：蓝紫径向星云、轨道光环和稀疏星点，作为通用默认背景。
2. **电离风暴**：青蓝电弧、流动粒子和高对比能量云。
3. **战术网格**：黑色基底、青色 HUD 网格、扫描线和坐标标记。
4. **跃迁裂隙**：紫橙高能裂隙、中心透视光和粒子拖尾。
5. **主权边界**：深蓝金色、星域边界线和轨道节点，适合主权军团。
6. **海盗暗潮**：黑红铜色、航线虚线和警戒标记，适合海盗军团。

背景与招募、介绍、活动三种内容版式任意组合。绘制顺序固定为背景、装饰层、暗部可读性遮罩、Logo/封面、文本和标签；背景不能降低正文对比度。背景选择保存到草稿内容中的稳定 key，未知 key 回退到 `deep-space`。

## 内容模型

现有 `Revision.content` JSON 继续承载新增字段，避免不必要的数据库迁移：

```json
{
  "corp_types": ["pirate"],
  "region_tags": ["highsec", "lowsec"],
  "benefit_keys": ["ship_reimbursement", "fleet_training"],
  "benefits_note": "新人有导师带队，定期发放舰队补给",
  "poster_background": "deep-space"
}
```

约束：

- `corp_types`：数组，允许 `pirate`、`sovereignty`，最多 2 项。
- `region_tags`：数组，允许 `highsec`、`lowsec`、`nullsec`，最多 3 项；中文显示为高安、低安、00 地区。
- `benefit_keys`：数组，使用固定福利预设，最多 8 项；保留 `benefits_note` 作为可选补充说明，兼容原有 `benefits` 文本。
- `poster_background`：六个背景 key 之一；缺失或非法值回退默认背景。
- `alliance`：继续使用现有短文本字段，不复制为第二套联盟模型。
- 所有数组在服务端重新校验、去重和限制长度，不能信任客户端角色或字段。

福利预设首批包括：`ship_reimbursement`（舰船补损）、`fleet_training`（舰队培训）、`industry_support`（工业/生产支持）、`logistics_support`（物流支持）、`newbro_mentoring`（新人导师）、`skill_sharing`（技能/知识分享）、`pve_fleet`（PVE 舰队）、`pvp_fleet`（PVP 舰队）。预设只负责标准化标签，补充说明仍由军团自行填写。

旧内容兼容规则：旧的 `benefits` 字符串继续公开显示；当 `benefit_keys` 存在时先显示结构化标签，再显示补充说明和旧文本（避免历史资料丢失）。

## 用户流程

1. 军团管理者在编辑页选择军团类型、区域标签和福利预设，填写联盟归属。
2. 在海报工作台选择任意背景缩略图；当前版式和输入内容不丢失，切换背景只更新 `poster_background`。
3. 预览时实时显示标签、福利和联盟信息；长标签折行但不撑破卡片或画布。
4. 提交审核时新增字段随不可变 revision 一起保存；公开目录和详情只读取已批准版本。
5. PNG 导出使用与预览相同的背景 key 和绘制参数，确保结果一致。

## 展示规则

- 目录卡片最多显示 2 个军团类型/区域标签，其余以 `+N` 收起；详情页显示完整列表。
- 福利列表在详情页显示为带图标的 chip，最多一行三项，窄屏自动换行。
- 海报默认展示最多 4 个福利 chip、最多 2 个类型 chip 和 3 个区域 chip；超出部分以“等 N 项”收束。
- 海盗使用铜红色、主权使用蓝金色；高安使用青色、低安使用橙色、00 地区使用紫色。标签颜色只作为辅助信息，必须保留文字。
- 当没有 Logo 或封面时，背景仍保持完整构图，不出现破图或空白大块。

## 验收范围

- 后端校验非法 key、重复值、超量数组和过长补充说明；旧 revision 仍能读取。
- 公开接口白名单只返回已批准版本中的新增字段，未审核草稿和上传证据继续隔离。
- 管理页可编辑并保存所有新增字段；重载后值保持；审核/发布流程不改变。
- 六种背景都能在预览和 PNG 导出中稳定绘制，文字对比度和中文换行可读。
- 目录、详情和海报在桌面/手机宽度下无横向溢出；背景切换不会触发页面崩溃。
- 保留现有 Community、全后端、前端构建和 E2E 回归证据。

## 非目标

- 本阶段不引入新的联盟、福利或舰船数据库表。
- 不做自由拖拽编辑器、成员权限体系、战报模块或线上生产部署。
- 不覆盖现有主库数据；新增字段仅写入新 revision JSON。
