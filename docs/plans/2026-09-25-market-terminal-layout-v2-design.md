# 市场终端固定一屏布局设计

## 背景

当前市场页仍沿用普通内容页的纵向流布局：页面两侧有白色留白，中间图表区域被 `flex` 最小高度撑长，盘口被推到页面底部，右侧摘要又没有足够的信息密度。用户需要一个类似交易终端的固定视口布局，在同一屏内同时完成物品切换、走势观察、盘口比较和报价状态确认。

## 目标

- 桌面端市场页铺满 `shell-main` 可用宽高，避免外层内容页留白。
- 桌面端一屏完成主要操作，不让图表空白把盘口推离视口。
- 保留现有数据查询、分类、价格历史、前五档盘口和刷新逻辑，不改变 API 契约。
- 切换物品继续复用上一份数据，避免页面闪烁。
- 平板与手机端继续可用：中等宽度折叠摘要，手机端恢复自然滚动。

## 方案

### 外层布局

给市场页增加 `market-page--immersive` 语义类，并在 `shell-main` 内通过 `:has()` 清除内容页的额外内边距；终端根节点使用 `height: 100%`、`min-height: 0`，由应用壳负责视口高度。市场页自身不再声明基于内容高度的 `min-height`。

### 桌面端

终端由三层组成：

1. `market-terminal-header`：固定 56px 的工具栏，包含标题、分类/搜索以及刷新动作。
2. `market-terminal-layout`：三列 grid，列宽为 `248px minmax(0, 1fr) 276px`，整体高度 `minmax(0, 1fr)`。
3. 中央主列内部使用三行 grid：仪表头、`minmax(0, 1fr)` 图表区、`206px` 盘口工作台。图表不会再依赖 SVG 的固有高度撑开父级。

左侧目录和右侧摘要独立滚动；中央主列默认不滚动，仅图表内部和盘口内容在需要时收缩。盘口工作台仍复用现有 `market-depth-panel` 和 `PriceLadder` DOM。

### 响应式

- `1100px` 以下：改为两列，摘要作为跨列底部区域。
- `767px` 以下：终端改为块布局，目录、图表、摘要自然堆叠，恢复页面滚动；图表最小高度降至 230px。
- 保持现有按钮、键盘焦点、ARIA 标签和测试选择器。

## 不做的事情

- 不改接口、缓存策略、采集频率或数据模型。
- 不引入新的图表库。
- 不在本次任务重做后台管理页或移动端视觉主题。

## 验收标准

- 市场页在 1440×900、1920×1080 视口下无横向溢出，终端占满主内容区。
- 选中物品后，图表和盘口在同一屏可见；页面不会因为图表无数据出现大片不可解释空白。
- 切换物品时上一份图表保持显示，直到新数据加载完成。
- 现有市场 E2E、shell 导航 E2E、暗色终端 E2E 全部通过。
- 生产构建和 `git diff --check` 通过，并用浏览器截图确认布局。
