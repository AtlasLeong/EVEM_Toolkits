# 两块战术板星系安等着色设计

## 目标与范围

战争沙盘板与海盗情报板的真实星图节点使用星系导航同一套安等色阶。只改星系点及其状态强调，不改变星门拓扑、坐标、目标/兵力卡、后端接口或可见权限。当前工作仍为本地预览，不推送或上线。

## 方案

把星系导航当前的五档颜色映射提到已有的 `securityColor.js`，三个使用者调用同一个纯函数。`≤0` 红、`(0,0.2)` 橙、`[0.2,0.5)` 黄、`[0.5,0.8)` 绿、`≥0.8` 蓝；缺失或非有限数值显示灰色，不把 `null` 误判为 0。现有星系导航颜色不变，缺失值修正为灰色。

两块战术板已经复用 `BoardStarGlyph`。该组件的星点填充色始终来自星系安等；选中、已上报及关联状态仍通过独立外圈/尺寸表达，不能覆盖填充色。星系名和安等文字保留现有深色地图的可读性配色。海盗目标、星座模糊范围和历史标记维持现状。

## 验证

先给色阶边界、未知值和共享 SVG 星点写失败测试，再实现。跑前端单元测试、生产构建，以及战争和海盗板浏览器回归；最后在本地真实星图页面检查红橙黄绿蓝节点、选中态和缩放后的视觉尺寸。
