# 战术板缩放与卡片清晰度：本地验证

日期：2026-09-23。范围仅限本地分支 `codex/tactical-map-card-clarity`；未推送、合并或部署。

## 已实现

- 滚轮按帧合并、限制单帧缩放幅度，并围绕指针缩放；达到上下限时不再触发无效视图更新。
- 记住首次可见卡片相对星系的方位。仅在确实遮挡星点、其他卡片、控件或越界时重新选位。
- 缩放过程中名称随真实星点平移，暂停重复的名称避让和星门索引计算；停下后结算。重点星系保持清晰，其他名称保持可读和可聚焦。
- 舰队与人数卡片共用 24px 居中的关闭控件；只给有权限的卡片预留按钮空间。关闭操作仍走已有权限、版本校验与确认流程。
- 归档、撤下确认框改为紧凑深色样式；修正失败态对比度、未知人数格式及手工部署的历史记录文案。
- 稳定人数管理回调，避免总览搜索触发不必要的地图卡片重新排布。
