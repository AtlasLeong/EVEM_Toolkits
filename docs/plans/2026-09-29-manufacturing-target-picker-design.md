# 制造目标分类选择器设计

## 背景

当前“切换目标”按钮只会把焦点移动到搜索框，目标结果只有输入文字后才出现；结果辅助信息还会展示内部 `productId`。这让目标切换不可发现，也把实现细节暴露给用户。

## 设计

将制造目标选择改成无新增依赖的分类选择器：

- 桌面端点击“切换目标”或当前目标卡，打开锚定浮层；移动端使用同一个 DOM 结构并通过 CSS 变为底部抽屉。
- 浮层顶部保留按名称搜索的搜索框，搜索不再匹配 ID，也不在任何用户可见文本中显示 ID。
- 目标按“舰船 / 材料 / 建筑”页签浏览；名称搜索跨分类分组展示，每组显示数量，空分组不渲染。
- 当前目标使用选中状态和勾选图标标识；选择后更新目标、关闭浮层并清空搜索。
- 支持 `Escape` 关闭、点击外部关闭和关闭后恢复入口焦点；Tab 限制在弹层内，页签及列表支持方向键导航。中文输入法组合输入不触发列表导航或关闭。
- 浮层通过 portal 挂载，避开页面 transform 的定位影响；桌面宽度至少 360px（受视口限制），低高度窗口不裁切，移动端为底部抽屉。
- 原有制造链路、报价和效率计算保持不变。

## 取舍

使用自研轻量 popover/drawer，而不是引入 UI 依赖，保持当前 bundle 和终端风格；交互语义参考开源 Radix/shadcn 的 popover、command、menu 和 focus-visible 模式。

- 执行制造页 E2E、全量单元测试、生产构建和 `git diff --check`。
