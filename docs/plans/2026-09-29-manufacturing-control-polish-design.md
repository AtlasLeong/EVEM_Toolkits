# 制造估价控件与刷新稳定性设计

## 目标

移除左下角公式卡，重做搜索与数量控件的边框和状态表现，并让数量加减只触发必要的制造结果更新，不重复触发行情检查或造成明显页面抖动。

## 交互方向

- 参考 shadcn/ui 的 Input Group、Button Group、Toggle Group 和 Card 组织方式，采用“低对比度底色 + 单层边框 + 明确 focus ring”。不引入 shadcn 依赖，保留现有 React/CSS 体系。
- 参考 Radix 的键盘焦点和 pressed 状态语义，保留 `aria-pressed`、`aria-label` 和 `:focus-visible`。
- 数量控件采用三段式稳定网格，数字使用 tabular numerals，按钮按下只改变局部背景，不改变尺寸。
- 搜索框只保留一层边框，聚焦时使用细琥珀色外环，不叠加浏览器默认 outline。
- 删除左侧“材料公式已核实”卡；公式说明保留在效率字段和右侧摘要，避免重复信息。

## 性能与数据流

- 数量状态继续即时更新制造树和成本摘要。
- 将购买项 ID 派生为稳定 key，数量变化但 ID 集合不变时不重新运行行情缺失检查。
- 保留现有报价缓存和手填价格，不改变 API 请求协议。
- 给数量控件、树节点数量和金额使用等宽数字，减少数字变化造成的布局位移。

## 验收标准

- 左侧不再出现“材料公式已核实”卡。
- 搜索框和数量控件无双重/厚重边框，focus-visible 仍清晰。
- 连续点击加减时数量即时更新，购买项行情请求数量不增加，页面不发生整块闪烁。
- 既有制造效率、路线切换、报价编辑和 150% 默认值行为保持不变。
- 桌面端和 520px 移动端回归测试通过。
