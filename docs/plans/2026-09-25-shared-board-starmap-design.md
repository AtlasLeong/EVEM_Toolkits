# 战争与海盗板共用星图底层

用户已批准：共用战争板底图，保留海盗目标层。先本地预览，不推送或部署。

## 设计

- 两种板共用星点、星门线、星系名称与安全等级的 SVG 绘制组件；保持战争板当前的 3px 普通星点、13px 名称、10px 安等及深色底图。
- 名称采用战争板的屏幕空间避让算法。海盗板先进行有界视口采样，再执行避让，避免 5000 星系触发无界碰撞计算。
- 海盗缩放借鉴战争板：连续滚轮仅逐帧更新图层变换，结束后提交状态、调整文字密度；名称使用淡入和减少动态效果偏好。
- 目标卡保留身份、船型、星系信息与常驻引导线。精确星系、星座范围和历史状态仍使用各自语义。
- 不修改数据模型、API、斥候可见性、上报/撤下权限、组织切换与手机端列表优先策略。

## 验证与风险

- 抽取仅改变公共绘制，战争板的交互包装、部署、人数、归档均留在原组件。
- 单测覆盖共享绘制、不同缩放级别、安等、滚轮合帧；浏览器回归两类板、密集星图、键盘、手机布局与缩放。
- 构建、分包预算检查、独立代码审查后交付本地预览，不以截图替代功能测试。
