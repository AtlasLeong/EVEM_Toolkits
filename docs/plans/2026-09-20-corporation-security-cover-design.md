# 军团驻地分级安等与默认封面提示

用户已确认方案。沿用本地 `codex/community-corp` 工作树，不合并、推送、部署或连接线上数据库。

## 驻地安等

星域、星座、星系分别展示自己的两位小数安等，覆盖目录下拉选项、收起后的选中值、编辑摘要、公开驻地和审核驻地。使用现有目录的数值与高/低/零安颜色；缺失、非数值不伪造为 0。

版本 JSON 驻地快照增加 `region_security`、`constellation_security`、`solarsystem_security`，仍保留兼容的末级 `security`。写入仍仅允许客户端提交三个 ID，服务器读取对应目录生成快照。旧快照缺少分级值时，仅把原 `security` 归属至其最深一级，不推断祖先安等，不修改已审核快照。无 schema 迁移；旧资料重新保存后获得完整目录值。

编辑页目录成功加载后可显示对应当前选项安等；加载中或失败时保留快照已知值，不丢名字、不错配末级数值。清除或切换上级应清理旧下级的名称和安等。

## 默认封面

军团编辑页未上传封面时，直接展示与公开页同一稳定默认横图，提示“当前使用默认封面，上传图片后可替换”。上传成功后去掉提示、显示上传图；移除后恢复同一默认图。上传失败保留原有图和错误处理。提示不影响保存、审核、徽标或海报背景，也不加到公开页。

## 验收

先补失败测试：三层数值各不相同、安等为 0/负值/缺失、旧快照、切换清空、只发 ID、默认封面三态。后端使用独立 SQLite 测试配置；前端使用既有回归框架和 CLI 截图检查桌面/手机。审核、上传和旧数据行为需保持兼容。
