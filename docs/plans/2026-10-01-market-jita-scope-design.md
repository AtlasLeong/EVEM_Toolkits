# 吉他海四市场范围标识设计

**目标：** 在市场页面明确标识当前价格来自吉他海四，避免用户将固定市场范围 8 误解为全宇宙报价。

## 方案

后端提供一个只读的市场范围元数据对象，固定对应当前协议范围 `8`：

```json
{
  "key": "jita_h4",
  "protocol_scope": 8,
  "label": "吉他海四",
  "description": "吉他 IV - 月 4 · 加达里海军装配厂"
}
```

物品列表响应和走势图响应都携带该对象，前端不再根据 `global` 生成“市场范围 8”文案。页面标题、当前物品标题和盘口摘要统一展示“价格范围：吉他海四”；后台保留协议 scope 的只读诊断信息，不开放编辑，避免采集范围被误改。

## 数据流与兼容性

- 价格快照表无需迁移，因为当前所有快照都属于同一个已确认的固定范围。
- 旧客户端忽略新增的 `market_scope` 字段即可继续工作。
- 未来支持多个市场范围时，扩展该元数据和快照联合键，不在本次变更中引入多范围迁移。

## 测试与验收

- 后端 API 测试确认 `/api/market/items/` 和 `/api/market/items/<id>/series/` 返回 `market_scope`，且协议 scope 为 `8`、展示标签为“吉他海四”。
- 前端单元测试确认范围标签优先使用 API 元数据，旧的 `global` 值只作为兼容回退。
- 市场页面端到端测试确认页面标题、物品标题和盘口摘要都可见“吉他海四”。
- 运行 Market Django 测试和前端相关单元/e2e 测试，确认历史走势、分类、报价和管理员页面没有回归。
