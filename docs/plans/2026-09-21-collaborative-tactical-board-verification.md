# 协同战术板 V1 本地验证记录

日期：2026-09-21。范围：`codex/tactical-collaboration`，基于军团功能提交 `8761dd7` 的独立工作树。未推送、未合并、未 SSH、未访问或迁移线上 MySQL。

## 交付范围

- 一个组织一张共享战术板，不设置需要斥候切换的房间。统帅/指挥可见敌我部署，斥候可见全部已确认敌方部署和自己的原始情报；敏感数据由服务端过滤。
- 邀请、申请、审批、角色管理与移除。指挥可审批新成员、移除当前斥候，不能移除指挥/统帅或分配角色。被移除成员仅统帅恢复，为待用户进一步确认的保守默认值。
- 100 个唯一在线账号的准入、人员与人数显示、多标签去重、在线续租、权限撤回。满员时仍允许有权限者处理人员管理，不多发地图名额。
- 快速填写人数与舰种数量、自己的情报修订、指挥明确确认/关联、直接维护部署、归档。未知人数与零人数不同；多次目击不自动相加，修订原始情报不暗改已确认部署。
- 局部星域与 0/1/2 跳边界，按真实星门邻接拖动同一部署；非邻接改址要求明确原因。人数及观察时间不会因移动被重置。
- 暖白站点外壳、深色局部地图、紧凑数字标记、敌我筛选、右侧情报面板、独立上报弹窗。手机显示列表/上报，不加载地图，保留原星系导航入口。
- HTTPS 命令、WebSocket 授权快照、断线重新获取快照与 HTTP 降级。UUID 幂等、版本冲突检查、权限代次和旧响应过滤；不自动重放失败的用户命令。

## 审查修复与失败记录

前后端实现分别经过另一位代理的交叉审查；主代理补充实时传输、集成与视觉审查。最终审查接受本地 V1，不等于批准生产或 MySQL 容量。

已修复审查项：满员页面角色降级后人员名单残留；审核弹窗自动提高版本而掩盖冲突；确认情报时缺少舰种详情；已采纳情报修订误建重复部署；空坐标变成原点；敌我筛选/边界出口/密集标记；组织创建响应丢失后的请求身份；混合 HTTP/WS 旧快照回写；权限撤回后迟到命令响应；同一逻辑租约被多个物理 WS 占用；深层 JSON、读取中 token 过期和已断开对端发送。

保留失败事实：

1. 首次本地 100 人测试遇到 SQLite 读写升级锁冲突。为**演习专用 SQLite 后端**使用 `BEGIN IMMEDIATE`，并加隔离防护测试；此修改不能作为 MySQL 行锁证据。
2. 对端已断开时发送引发传输异常，增加关闭竞态与精确异常类型处理；不吞掉任意运行时错误。
3. 一次 600 秒测试测得 p95 1.64 秒、最大 3.50 秒，但最后两次广播因测试器在截止时提前退出而未确认，**该次结果记为失败**。补充有上限的尾部确认等待及回归测试后再完整复测，不能仅凭前面的延迟数字宣称通过。
4. 之前一次旧页面浏览器回归为 210/211，星图重置断言失败；当时有并行源码热更新和测试输出目录冲突。未改旧星图逻辑，分离输出目录、冻结源码后串行完整重跑，211/211 通过。
5. 源码冻结后，与浏览器回归同时运行的 100 人测试持续 600.02 秒，59 次更新 / 5900 次观察，`errors=[]`，p95 **2.437 秒**、最大 **4.890 秒**，仍因 p95 不满足 `<2s` 退出失败。保持代码、负载参数和门槛不变单独复测。并行浏览器可能带来 CPU/磁盘调度竞争，但不是已证明的唯一原因；测试夹具保留历史部署，每次增加两个部署，因此不同轮次数据量也略有增加。

只读性能复核发现：WS 的 `socket_snapshot → snapshot` 重复读取组织/账号/成员/租约并开启嵌套事务；未变化的数据仍完整查询并计算摘要；默认线程敏感数据库执行器和本地 SQLite 串行事务有排队成本。后续可在同一个授权事务内复用私有快照构建器、评估内部变更检测，但不能取消当前权限/租约检查、向斥候暴露私密事件编号，或未经验证直接改成不受控线程并发。此轮基线复测不混入这些代码修改。

## 尚未通过的发布门槛

- 当前机器 Docker 服务未启动，没有独立 MySQL 实例；未验证真实 MySQL 多 worker 下的并发准入、同版本竞争、移除/写入竞争、重启恢复。
- 本地 100 人测试只覆盖小记录量；不覆盖 1000 个活跃部署 / 5000 条累计报告上限、慢客户端、重连风暴或生产硬件资源曲线。
- 单主机时间戳顺序策略尚未证明多主机/时钟回拨的严格有序性。
- 原计划增量事件回放在 V1 改为完整授权快照恢复；没有历史回放界面。
- 邀请主动撤销、报告保留/归档策略、操作历史浏览界面、附件/OCR、具体舰船型号选择、舰队拆分合并属于后续范围。审计记录已持久保存，但不能描述为已有可浏览的历史 UI。
- 本次 CI 配置只做增量添加，未推送触发远端 GitHub 构建。生产 ASGI、代理 Origin/TLS/限流、备份和迁移仍需独立审核。

结论：按上述范围提供本地体验版；不可将本记录描述成“生产 100 人容量已验证”或“已经上线”。
