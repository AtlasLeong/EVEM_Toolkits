# Manufacturing Terminal Redesign Design

## Goal

重做制造估价页，使它与市场页共享终端式视觉语言，并让路线选择、选中态和大额 ISK 金额在第一眼可读。

## Visual direction

- 复用市场页的深色终端画布、细分割线、青色/琥珀色语义色和三栏信息架构。
- 左栏负责方案设置、制造目标、技能与效率；中栏负责制造路线与多层级树；右栏负责总成本、成本拆分、市场参考价和手填价格。
- 每个可制造节点使用明确的「自造 / 购买」双段控件。当前状态同时通过填充色、文字反差、勾选图标和外侧色条表达；基础材料使用固定的“市场采购”状态。
- 当前节点使用高对比焦点框和节点左侧 accent bar；键盘 focus-visible 使用统一 focus ring。
- 精确金额保留两位小数，同时显示紧凑金额，例如 `47,082,080,424.40 ISK` 与 `约 470.82 亿 ISK`。小于一亿显示“万 ISK”，大于等于一亿显示“亿 ISK”。

## Interaction and data flow

- 保留已有制造目标搜索、数量、技能等级、效率百分比、生产建筑、蓝图状态、路线展开/收起和市场报价逻辑。
- 切换目标时清理路线覆盖和方案手填价格，避免不同配方互相污染。
- 点击节点正文只改变当前查看节点；点击路线双段控件只改变该节点的生产方式，并保留现有树裁剪/恢复行为。
- 右侧摘要根据当前 plan 实时更新；缺少报价时同时展示已覆盖小计和缺失数量。

## Scope

- 修改制造页 JSX 的展示结构与可访问性标识。
- 重写制造页 CSS，删除旧的浅色/青绿色视觉规则，改为市场终端的 scoped tokens。
- 添加金额紧凑格式化的单元测试和路线/选中态的 E2E 断言。
- 不改制造计划计算、市场报价接口或其他页面。

## Verification

- 制造相关单元测试覆盖 `formatCompactIsk` 的万/亿边界。
- 制造 E2E 覆盖目标选择、路线切换、选中态可见文本/ARIA 状态和紧凑金额文案。
