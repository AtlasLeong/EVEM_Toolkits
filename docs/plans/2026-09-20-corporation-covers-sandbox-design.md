# 军团默认封面、海报精简与本地沙盒设计

用户已确认新增四款专用横图；本次仅本地实现，不推送、合并或部署。

## 视觉与行为

- 海报三种模板均移除顶部 `EVEM / ...` 与已审核海报底部平台声明。军团简称、模板名、军团信息和联系方式保留；未审核草稿标记不在用户框选范围，保持现有行为。
- 新生成舰队、行星、船坞、星云四款无字横版封面，用于列表与详情顶部的缺省图片。构图适配窄横幅和移动裁切，主要视觉留在中央安全区，延续已有宇宙写实审美。
- 缺省封面根据军团 ID/名称稳定分配，刷新不随机变化；自定义上传优先，上传读取失败回退默认封面。保留当前紧凑封面高度、文字 Logo 回退和八款竖版海报背景，不扩展为新封面编辑系统，不增加数据库字段。
- 不自动把缺省横幅嵌入竖版海报的自定义图片小框；竖版海报本身已有八款默认背景。

## 本地可操作沙盒

已确认根因：4190 服务拒绝登录，只支持固定军团的少数读取/保存接口；创建、审核、token 刷新及 multipart 上传缺失。此前 E2E 拦截绕开了该服务。

- 保留独立 `tests/preview` 服务，严格绑定 127.0.0.1，不请求或转发生产。
- 提供明确的本地测试入口与身份切换（游客、军团管理员、审核员），不使用真实账户密码；如果打开正常登录表单，应有清楚的演示入口/说明，不再让用户猜参数。
- 完整支持创建/认领申请、审核申请、编辑草稿、保存、提交/撤回、审核发布、再次创建草稿以及动态 ID；普通身份不能审核，发布前不泄漏草稿。
- 支持 PNG/JPEG/WebP、5 MiB 限制的本地图片上传与读取，海报能够使用这些图片；图片验证与生产策略一致。
- 预览状态保存在服务内存，刷新页面保留，服务重启重置；页面醒目提示这一边界。不清空无关 localStorage，不提供危险的生产访问后门。
- 通过实际服务的 HTTP 测试和不拦截 API 的浏览器测试验证闭环，而不是另建不一致的模拟流程。

## 验收

四款真实横图已入项目；无图/坏图/自定义图和桌面/手机视觉检查；三种模板去字与导出回归；实际本地服务从入口创建到审核发布、上传、编辑、刷新留存与角色隔离；既有前端构建和相关回归通过。
