# 制造估价终端重设计方案

## 目标

将制造估价页重做为与市场页一致的高密度深色交易终端，解决当前首屏层级混乱、左侧配置过高、制造链被挤压、按钮配色割裂和移动端横向拥挤的问题，同时保留现有制造计算、路线切换和报价编辑能力。

## 视觉方向

- 外层采用深石墨蓝背景，不再使用浅色页面外壳与青绿色表单混搭。
- 主色统一为暖琥珀，用于关键操作、当前效率、制造路线和总成本强调。
- 冷蓝灰只用于信息层级、边框和次要交互；绿色只表示“已完成/报价完整”，不再作为默认按钮底色。
- 自造与购买不使用两种高饱和底色互相竞争：默认使用同一中性控件，选中状态由左侧强调线、图标和短标签区分。
- 文本分为高亮标题、正文、辅助说明三级，减少小字号和过度字重。

## 页面结构

1. 顶部目标栏：制造目标、数量、效率、当前路线状态和刷新动作放在一行，减少巨大的页面标题占用。
2. 左侧方案栏：只保留目标搜索、制造数量、最终材料效率和蓝图状态；技能/建筑预设继续折叠并明确“待接入”。
3. 中央制造链：占据主要宽度，采用扁平层级列表。根目标固定在顶部，中间件通过缩进、连接线和节点序号表达层级；路线切换控件保持在每行右侧。
4. 右侧成本栏：固定显示总成本、紧凑金额、材料/制造/蓝图拆分、缺失报价和当前节点报价编辑，不再留下大块空白。
5. 移动端：按目标栏、效率卡、制造链、成本摘要顺序纵向排列；路线按钮保留文字，不退化为图标-only。

## 交互与数据

- 不修改制造计算接口和材料效率公式；本次只调整布局、样式及必要的可访问性标记。
- 目标切换、展开/收起、批量路线策略、购买节点手填价格继续使用现有状态流。
- 当前效率输入继续显示最终效率百分比，默认 150%，最低 75%。
- 路线状态提供清晰的 `aria-pressed`、选中边框和文本状态，避免仅靠颜色传达。

## 响应式与性能

- 桌面端使用固定三栏网格，中央栏 `minmax(0, 1fr)`，避免内容撑破视口。
- 各栏仅在内容超出时独立滚动，页面本身不产生双滚动条。
- 移动端取消三栏网格，减少阴影、渐变和装饰线，保证滚动流畅。
- 继续复用现有图标和组件，不新增图片资源或运行时依赖。

## 验收标准

- 1440×960 桌面视口首屏能同时看到目标栏、制造链主要节点和右侧成本摘要。
- 520px 移动视口无横向溢出，效率输入和自造/购买文字清晰可见。
- 自造/购买按钮在默认、悬浮、选中、禁用状态下具有统一的终端视觉语言。
- 现有制造单元测试和制造页面 Playwright 回归保持通过。
- 视觉修改不改变 150% 默认效率、75% 下限和逐批向上取整行为。
