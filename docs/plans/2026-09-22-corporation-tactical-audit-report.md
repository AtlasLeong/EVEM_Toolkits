# 军团 / 战术板深度审查与修复报告

日期：2026-09-22。范围：当前 `.worktrees/tactical-collaboration` 工作树的军团与战术板前后端，包含此前尚未提交的实现。保留所有原有修改；本轮没有提交、合并、推送、部署或访问生产数据库。

## 审查方法与结论

按系统化调试、测试驱动修复与独立代码复核执行：先查调用链与根因，再观察新回归测试失败，最小修复后重新运行。三个独立审查方向分别覆盖军团后台、军团前端、战术后台，主代理负责战术前端与联合验收，并交叉复查修改。

已处理 14 类确认问题（成员异步读取包含乱序、请求堆积和超时恢复等同一生命周期问题）。未发现新的直接跨角色越权泄露；既有草稿审核隔离、斥候不见己方部署、稳定舰队 ID、乐观版本校验、人数上报不重复累加均保留。这不是“所有场景零缺陷”或“已通过生产容量验收”的声明。

## 已修复：军团

| 问题 | 修复与证据 |
|---|---|
| 运行时图片存储检查落后于发布预检 | 上传与读取统一复用只读预检，拒绝公开/发布切换目录、项目目录及未配置的存储根；合法前缀式 STATICFILES_DIRS 不再导致 500。新增 6 项真实 API 回归。 |
| 非对象 JSON 申请触发 500 | 在字段判断前检查对象类型；null、布尔、数字等返回 400，不写数据库。 |
| 驻地 ID 非法 Unicode 触发编码异常 | 星域、星座、星系 ID 复用既有 Unicode 校验；返回 400，草稿内容和版本不变。 |
| 审核最后一条导致空分页且无返回入口 | 数量缩减后自动回到有效页，保留当前编辑器。 |
| 旧审核响应关闭新选中的审核详情 | 按审核类型与 ID 核对当前选择，保留另一条审核意见。 |
| 上传失败重试绕过保存/上传忙碌锁 | 重试入口遵守父级操作锁和当前上传状态，完成后仍可重试。 |
| 大厅全部上传图片提前获取 | 卡片进入视口前 300px 再加载上传徽标/封面；无 IntersectionObserver 时正常降级。20 卡片手机测试首屏请求 40 → 2，滚动至末卡后累计 6；该数字仅适用于测试场景。 |
| 创建/撤回成功但后续 GET 失败时仍显示旧版本 | 立即采用成功操作返回的已确认版本，不依赖随后重取；测试确认新 revision ID/version 用于继续保存。 |

另新增分页查询数保护：21 条记录分别返回 20/1；公开列表与审核队列各 2 次 SQL，个人双集合 4 次 SQL（隔离测试使用 force_authenticate，不包含 JWT 身份查询）。未发现按卡片条数增长的 N+1，因此没有做无依据的查询重构。

## 已修复：战术板

| 问题 | 修复与证据 |
|---|---|
| WS 每轮快照重复锁定/授权查询 | 合并在同一受保护事务内读取，保留当前身份、角色、连接租约、唯一 socket generation 检查；斥候每轮 SELECT 11 → 7。缺失 generation 不允许退化为普通 HTTP 租约检查。 |
| 旧星系数据非有限安等导致搜索 500 | catalog 复用有限数字清理，将未知/非法数值作为 null，而不是伪造安等。 |
| 切换/刷新时迟到的入场请求残留连接占位 | 请求结束后再次释放被取消的原连接 ID，避免先 DELETE 后创建的租约残留；不会清除新组织/新标签页租约。完全断网仍以服务器 60 秒过期为兜底。 |
| 局部星图临时加载失败无法恢复 | 提供当前战术板内的“重新加载星图”，旧范围/组织请求继续失效隔离。 |
| 输入列表搜索触发无关地图布局计算 | 稳定 forces 与 reports 输入引用；全部阵营及仅己方均用真实算法调用计数测试确认输入搜索不再触发布局计算。 |
| 成员名单读取乱序及网络挂起 | 操作后旧响应不可回写；轮询单飞；操作或卸载取消旧读；15 秒独立截止并自动恢复轮询，也覆盖共享 token 刷新挂起的阶段，不取消全局登录刷新。 |

性能边界：100 账户、100 舰队、100 报告的**顺序内存 SQLite**快照轮次为 700 SELECT，代理独立测试 1.531 秒、主代理与其他回归并行时 2.754 秒。此测量用于查询数量与 N+1 防护，绝不是 100 人实际网络延迟、并发压测或生产容量结论。当前仍会定时完整读取/序列化授权快照。
