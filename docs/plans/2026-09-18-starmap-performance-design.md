# 星图性能优化设计

用户已批准 2026-09-18 的性能评估建议。保留 Canvas、现有界面、路径接口和算法，不重写 WebGL，不发布生产。

## 选择与范围

- 采用渐进式 Canvas 优化：仅尺寸/DPR 变化时重设 backing store；绘图层对无向星门去重；用带余量视口裁剪星点与星门包围盒（保留两端在外但穿过视口的线段）。
- 拖动/滚轮输入累积到同一帧提交，立即更新相机 ref 供下一事件与命中使用。交互期间暂停名称与光晕，结束后恢复。保留定位动画、DOM 标记同步及卸载清理。
- 星图四组低频数据使用一小时内存 freshness/retention，仅影响星图查询，重新加载页面仍请求；不缓存用户数据、路线结果或错误。
- 暂不采用多层画布/Worker/WebGL：复杂度较高，先量化当前改动收益。
- 暂不变更服务器压缩、数据库、发布工作流；未压缩接口仍为后续独立优化项。

## 验证

先运行既有星图测试。新回归用实际 Canvas 绘图方法包装计数而非替换画布：宽高赋值、星点、线段及背景绘制次数；覆盖穿屏连线、缩放/平移、窗口变化、快速连续滚轮和卸载。补一组接近线上规模（5,428 星系）的固定夹具，输出优化前后绘制工作量及本机时序采样，不把计数下降说成 FPS 提升。
