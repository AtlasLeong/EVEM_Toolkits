# 战术板运行时决定与上线边界

## 当前实现

独立功能分支 `codex/tactical-collaboration`，基于已完成的军团功能 `8761dd7`。保留 `/starmap`、原寻路、WSGI 和生产发布流程。新增 `/tactical`、`/api/tactical/`，可选 `/ws/tactical/<organization>/`。

固定可选依赖：Channels 4.2.0、Uvicorn 0.34.3、websockets 15.0.1，位于 `backend/requirements-tactical.txt`；不偷偷替换全项目运行时。本地 Python 3.11 / Django 4.2.5 验证，CI 使用 Python 3.10。

参考官方资料：[Channels 安全说明](https://channels.readthedocs.io/en/stable/topics/security.html)、[Channels 4.2.0](https://pypi.org/project/channels/4.2.0/)、[Uvicorn 0.34.3](https://pypi.org/project/uvicorn/0.34.3/)、[websockets 15.0.1](https://pypi.org/project/websockets/15.0.1/)。

V1 选择 **HTTPS 命令 + WebSocket 授权快照 + HTTP 降级**。不用 Redis 或内存房间状态；数据库保存组织、成员、情报修订、部署、审计、幂等回执和在线租约。组织行锁统一串行化权限变化、写入和准入。

原方案中的“增量事件重放”替换为“断线重新读取完整授权快照”。每条连接约 1 秒检查一次，授权视图变化才发送；没有向斥候泄漏私密事件总序号，也没有声称实现历史回放 UI。前端每 20 秒通过认证 HTTP 续租并校验状态；工具客户端可发送 WS ping。无长连接时每 2 秒 HTTP 更新，恢复连接不自动重放用户命令。

前端混合 HTTP/WS 快照按权限代次及组织锁内生成的 `server_time`（保留微秒）过滤旧响应，防止延迟帧恢复旧部署。该策略假定同一应用主机时钟一致；多主机/时钟回拨的严格顺序验证是后续上线门槛，不能据此声称分布式事件总序已实现。

## 安全与限制

- 创始统帅/指挥可见敌我及全部原始上报；斥候收到全部敌方部署、自己的原始上报和在线人数，**不收到**己方、他人报告、人员名单、私密历史或对应统计。
- 所有 REST 读与 WS 快照按当前数据库权限投影，不把隐藏权交给前端。HTTP 返回 `Cache-Control: no-store, private`。
- 首帧 JWT，5 秒认证期限、4096 字节帧限、每分钟 30 帧上限；精确 Origin 白名单，禁止 URL query 凭据；发送等待上限 5 秒。反向代理仍需连接/握手速率限制，应用限制不代替抗流量攻击。
- 100 个唯一在线账号，最多每账号每组织 4 个逻辑连接；60 秒租约，20 秒心跳，30 秒未心跳显示重连中。满员不额外放行统帅，但人员管理不占地图名额。
- 每条物理 WS 使用服务端生成的租约代次。替代连接使旧连接在下一次读取/心跳失效，HTTP 续租不能复活旧代次；每逻辑连接每分钟最多 12 次替代。关闭旧 WS 不删除新的租约。
- 请求 UUID + 内容摘要幂等；权限检查先于回执。部署、地图范围与报告采用版本冲突检查；UI 固定用户审核过的版本，不随后台更新悄悄提高版本号。
- 原始情报修订不覆盖已确认部署；再次采纳明确关联现有敌方。部署归档保留历史，前台不再展示；拖过星门保留部署 ID、人数、原观察时间。
- 组织最多 20 个范围星域，系统搜索最多 30 条；0/1/2 跳边界是真实服务器裁剪。静态图缓存 5 分钟，键含范围和数据版本，不缓存私密军情。
- 当前上限 1000 个未归档部署 / 5000 条累计报告；小数据量负载验证不等于此上限性能保证。报告达到上限前需规划保留/归档机制，目前不会偷偷删除历史。邀请有期限但本版暂无主动撤销入口；未实现附件、舰队拆分合并、历史回放、舰船具体型号目录选择。

5. 代理单独转发 `/ws/tactical/` Upgrade/Connection 请求，启用 TLS、合理空闲超时、握手/连接数限流；不要将 JWT 写入 URL/日志。HTTP API 可以仍走经验证的 Django 服务，但应共享同一数据库和权限设置。

7. 回滚应用可关闭新入口并回到原 WSGI；不要删除新增表或逆向迁移用户军情数据。保留备份和审计，单独评估新数据兼容性。

本次不 SSH、不推送、不合并、不迁移线上 MySQL，也未宣称具备直接上线资格。
