# 制造成本规划器：设计稿（待预览确认）

日期：2026-09-28。状态：仅设计与静态预览，未开发、未部署。

## 目标与范围

用户选择舰船、工业材料或建筑及目标数量，得到“按当前方案取得所有投入品并完成全部制造步骤”的成本估算。弹药不在首版范围。默认把有配方的中间产物自行制造；用户可逐项改为从市场购买。市场观测价只是参考，用户可以为**当前制造方案**填写采购单价，保存方案后仍可复用，但不得修改共享市场行情。

已核对的客户端数据包含本范围 503 条制造配方（舰船 366、建筑 106、工业材料 31）。依赖图无环，最长三层；其中 115 种投入品可继续制造、63 种是在当前范围内不能再展开的终端采购品。63 种终端采购品并非全是基础矿物：按网站当前分类为行星资源 29、矿物 8、其他 26；“其他”包含基础舰船、高级制造材料、富勒烯/月矿等。当前三类自动采集仅覆盖其中 37 种，准确估价须补充其余品类的行情或由用户手填。此前核出的 23 种缺网站目录的中间产物均有制造配方；默认自造时不依赖它们自己的市场报价。

## 方案选择

采用“全链自造为基线、逐节点手动改为购买”的方式。相比纯自造，它允许用户根据真实库存和交易条件调整路线；相比自动为每项选择账面上最便宜的路线，它不会把单档最低卖价误当作大数量均可成交的采购价。自动最便宜路线不在首版范围。

## 术语与价格边界

- **制造方案**：目标产品、数量、效率设置、各中间节点买/造选择及本方案的手填采购价。
- **制造节点**：有本范围内配方的产品；默认继续展开并计算本层投入、批次数与本层制造费用。
- **终端采购品**：在本范围内没有可继续展开配方的投入品。它可能是矿物、行星资源，也可能是基础舰船等，不能统称“基础原料”。
- **市场参考价**：最近一次盘口观测到的最低卖价，附观察时间与新鲜度状态。它不是成交价，也不保证订单数量足以满足生产需求。最高买价不用于采购估算。
- **本方案采购单价**：实际参与本方案成本计算的价格。用户手填时标记“手填”，可一键恢复市场参考价；仅在该方案内保存，不回写共享快照或其他方案。
- **方案总成本**：被选择购买的终端品/中间品支出，加上保留的制造节点逐层费用及本方案计入的蓝图费用。仅所有必需价格和费用都有依据时展示完整总额；否则显示已覆盖小计、缺口与原因。

## 交互与布局

桌面端沿用现有 EVEM 外壳：浅色侧栏和页头，内容区采用高对比度深色工作台，并保留与战术板相近的外侧留白和圆角边框。工作台固定一屏，左侧方案设置、中间制造树表格、右侧成本与所选节点价格编辑；制造树和明细各自滚动，不让整页被长清单撑高。窄屏按目标/汇总、制造树、价格编辑依次堆叠。

1. 左侧选择制造大类、搜索目标物品，设置目标数量、技能/效率与建筑条件，并显示蓝图费用口径。
2. 中间按层级展示制造节点和终端采购品。每个可制造中间节点有显眼的“自造 / 购买”开关；选择购买会截断该节点以下的制造链，改用采购单价。切回自造恢复子树。
3. 每行显示需求量、市场最低卖价/采集时间与实际采用的价格来源。购买节点和终端采购品可在右侧编辑本方案采购单价；自造节点的市场价只用于比较，不进入总成本。
4. 右侧按终端采购、中间产物购买、逐层制造费用、蓝图费用分项合计；列出未报价、空卖单、超过时效的项目，并明确影响哪些总额。

静态桌面预览采用“组装车间模块 IV”示例，将模块 II 设为购买、模块 I/III 保持自造。结构与终端采购品计数参考已提取的配方；显示的材料量是未应用技能/建筑效率的原始配方聚合量。市场单价、手填价及已知采购小计仅为排版示例，不代表真实报价或已实现的完整计算。当前行情目录没有模块 II 的参考价，故预览展示“未收录＋本方案手填”，而不是虚构市场价；其余所需报价和制造费用未完整核定前，不展示完整总成本。

## 计算与异常规则

配方图以产品 ID 为键；按目标数量与每批产出计算批次数，逐层向下聚合材料需求，并在每个制造步骤分别应用经过核实的材料效率、费用及建筑/技能修正。12 条配方每批产出 200，其余 491 条产出 1，必须对每层批次数向上取整并显示余量；超过 `max_install_quantity` 时拆分安装。计算使用十进制/整数金额，不使用浮点数累积大额 ISK。共享中间节点和报价按 ID 缓存，方案结果按采购与制造路线聚合而非逐行重复求和。

市场接口需支持有界批量查询所需物品的最新报价、观察时间和状态。当前采集器只记录价格档位，没有订单数量，因此显示“参考单价”；过期、空卖单、未采集和未在目录中的项目不可静默按 0 或旧价计算。用户可明确输入方案采购价补足。手填价及路线随用户自己的方案保存；未登录用户可临时试算，但不跨设备保存。

蓝图是否已拥有及本次应计蓝图费用作为方案参数明示；不擅自把蓝图取得成本假定为零或把可重复使用成本全部摊到单件。首版上线前仍需核对游戏实际技能、建筑、安装费与蓝图消耗/摊销公式；公式未验收时不得把估价标为精确成本。

## 验收重点

- 默认全自造与任一中间品改为购买两种路线的总额差异可追溯到具体节点。
- 手填价只影响当前方案，恢复市场价后不残留覆盖；共享行情快照保持不可变。
- 多批产出、余量、拆单、同一投入品多处复用时数量与费用正确聚合。
- 无价或旧价时不得显示“完整总成本”；显示缺口列表，允许用户手填并重新计算。
- 大数量报价仍标为“盘口最低卖价参考”，不承诺可按该单价买足。
- 手机与桌面均能清楚辨别路线、价格来源、时效和成本分项。

## 当前边界

这份设计与预览不修改生产应用、不启用新物品采集、不改变现有市场数据库或线上服务。用户确认预览后，再另行制定实现与测试计划。
