# 全项目视觉对比度与层级设计

## 背景

线上页面同时使用暖中性内容页与深色星图。当前问题不是缺少装饰，而是多个页面各自维护灰绿色文字、边框和选中态，导致输入提示、元信息、侧栏标签和分隔区块在实际背景上不够清楚。此次改造以可读性优先，保留现有品牌和地图视觉方向。

## 目标

- 让正文、次要信息、辅助信息形成稳定的三级层级。
- 让输入框、卡片、Tab、筛选器和状态在浅色与深色背景上都能被快速识别。
- 提升战术板侧栏与星图叠层的可读性，但不把星图改成浅色页面。
- 修复移动端关键按钮、搜索框和详情操作的拥挤风险。
- 通过自动化对比度与响应式回归，避免后续样式覆盖再次降低可读性。

## 设计原则

1. **暖中性内容页 + 深色地图子主题**：不做全站深色重构，内容页面保持现有纸面感，战术地图保持暗色空间感。
2. **语义化颜色而非随意变黑**：正文使用高对比墨色；次要信息仍保留灰绿色，但达到至少 4.5:1；仅装饰性辅助文字允许更弱且字号不低于 13px。
3. **状态不只靠颜色**：选中、告警、过期、敌我等状态同时使用背景、边框、图标或字重表达。
4. **关键数据优先**：人数、星系名、时间、上报者、来源和操作按钮不使用 9–11px 的弱文字。
5. **稳定的控件边界**：输入框和分隔线使用更明确的边框或 surface 差异，焦点环统一。

## 视觉系统

### 浅色内容页

- `ink`：正文和标题；目标对比度至少 7:1。
- `muted`：标签、辅助说明、位置和时间；目标至少 4.5:1。
- `quiet`：纯辅助提示；仅用于 13px 以上非关键内容。
- `line`：从当前过浅的分隔线调整为可感知的边框，并以背景层级补足，而不是依赖单条线。
- placeholder 不再使用全局透明度削弱，改用明确颜色。

### 战术板

- 侧栏统一使用浅色 `tactical-surface`、`tactical-ink`、`tactical-muted`、`tactical-line` token。
- 未选中 Tab 提高对比度；选中 Tab 同时增加文字、底边、背景或图标信号。
- 人数、星系、观察时间、上报者和来源的最小字号为 12px；10–11px 只保留给非关键辅助信息。
- 地图未激活星门线设置可见度下限；激活线通过亮度和粗细增强，不增加持续动画。
- stale 状态只降低状态标识，不降低整张卡片的整体 opacity。

### 移动端

- 搜索、Tab、主操作保持至少 40–44px 触控高度。
- 长中文操作在 390px 宽度下允许换行或改为两列/整行布局。
- 战术侧栏在窄屏以底部抽屉/纵向面板呈现，避免地图与侧栏争夺同一横向空间。

## 影响范围

- 全局 token、placeholder、按钮和表单边界：`front-codex/src/styles.css`。
- 战术板侧栏、总览和暗色地图：`front-codex/src/styles/tacticalCollaboration.css`、`tacticalOverview.css`、`tacticalMapIntel.css`。
- 星海见闻搜索、表单、战报详情和移动端操作：`front-codex/src/styles/starsea.css`。
- 军团搜索、导航和详情操作：`front-codex/src/styles/corporations.css`、相关组件。
- 视觉回归：`front-codex/tests/e2e/specs/warm-contrast.spec.js`、战术 E2E、移动响应式 E2E；新增纯函数/样式契约测试只覆盖可验证的 token 和状态语义。

## 不做的事

- 不更换品牌 logo、页面信息架构或后端数据模型。
- 不把所有页面改成黑色科幻风。
- 不用动画或阴影替代信息层级。
- 不通过降低字号来解决密集布局。

## 验收标准

- 关键正文、控件文字和 placeholder 达到 WCAG AA 对比度目标；非文本控件边界有稳定可见信号。
- 三张反馈截图中的低对比问题消失：战术侧栏、星图筛选器、军团/星海搜索框均可快速区分。
- 390px 宽度下军团详情操作、星海编辑器操作和战术侧栏不发生文本截断或横向溢出。
- 地图缩放、拖拽、连线和既有上报操作回归测试继续通过。
- 本地构建、单元测试、E2E 与线上预览验证通过后，才进入生产发布。
