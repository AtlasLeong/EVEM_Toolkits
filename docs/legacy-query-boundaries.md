# 旧查询边界与邮件韧性

本次保留现有 Django/DRF、MySQL、React Query、权限和采集架构。以下是单次
请求的保护策略，不是完整的数据库扫描量或响应时间承诺。没有新增任务队列、
共享缓存服务、表结构、后台采集预算或游戏请求。

## 行星与地点目录

- `/api/searchplanetresource` 仍接收查询对象、返回原平铺数组。每级地点数组最多
  100 个提交项，资源数组最多 34 项；先检查原始数量，再稳定去重。
- 地点 ID 是正的有符号 64 位十进制整数，兼容整数及数字字符串，不接受布尔、
  浮点、空段或嵌套对象。资源 `value` 必须来自服务器目录；旧客户端的
  label/group/icon 选项形状仍可提交，但返回图标取服务器目录。
- 保留最深一级地点优先及每颗行星首个匹配资源的原有行为。全模型候选最多
  5,000 行；预计算表一次读取最多 10,000 行；目录返回最多 10,000 行。
  SQL 使用上限加一检测超量，超量返回 400 要求缩小条件，不返回假完整排行榜。
- 全宇宙资源最大值从同一预计算表一次有界读取后计算，保留各资源/星域的并列
  最大值、请求资源顺序及原始字段。地点 Top 3 按有限、非负数值排序，跳过空值、
  非法值、布尔、NaN/Infinity 和浮点溢出值；不改写原始产量字符串。
- `/api/constellations?regionID=...` 与 `/api/solarsystem?constellationID=...`
  保留数组响应。CSV 最多 100 项、2,000 字符；缺失、空段、重复参数和非法 ID
  返回 400。军团地点选择器继续使用这些接口。
- 行星页面显示安全的 400/429 指导，失败时保留上次结果；不自动拆分查询绕过
  工作量或请求预算。

## 集市图表

`POST /api/bazaarchart` 保留序列数组请求及嵌套曲线数组响应。当前前端没有新
集市页面；此接口兼容历史调用，不为这次保护工作新增页面。

- 最多 8 个原始提交条目，稳定去重后按请求顺序返回。
- 条目只含 `bazaarName/server/rank`。名称非空且最多 255 字；服务器兼容
  china/world 大小写；排名为 1～50 的整数或 ASCII 数字字符串。
- 每条曲线最多 366 个历史点，单条合并 SQL 最多读取
  `去重序列数 × 366 + 1` 行，最多 2,929 行，日期/主键排序稳定。
- 任一曲线或总量超限明确 400。不得截掉历史后把剩余数据重新标成“第 1 日”，
  造成完整走势的错觉。未知服务器和错误形状在读取数据前拒绝。

## 防诈管理流水

`GET /api/fraudbehaviorflow` 仍要求有效登录及当前防诈组授权，每次重新检查；
staff/superuser 身份不替代业务组权限。

- 无参数旧请求返回有界第一页数组。新请求显式带 `page=1&page_size=20`，返回
  `count/results/page/page_size/has_next`。默认 20、最大 50 个操作，页码最大
  10,000，拒绝未知/重复/非法分页参数。
- `count` 是授权范围内非 F 操作锚点数量，不是原始流水行数；按主键倒序稳定
  分页。当前页的修改后 F 版本也受同一授权范围过滤，跨组无权版本不能补出。
- 每个非空操作 ID 最多取一条最早主键的授权 F；旧空/空白 ID 不配对。每页
  最多 100 条原始行，操作人与姓名批量读取一次；找不到用户时仍返回 null。
- 前端仅进入修改流水页签时读取当前页，支持上一页/下一页，保留前后详情；
  兼容滚动部署期间旧数组，不把本页数量冒充全局数量，不自动加载全部历史。
- 私有响应标记 `private, no-store`。不改变举报、证据上传、审批和写入流程。

## 独立读取预算

行星查询为 30 次/分钟，集市图表为 60 次/小时；与邮箱/登录预算分开。
只信任连接的 `REMOTE_ADDR`，不信客户端 X-Forwarded-For。沿用现有 Django
cache，可能是进程内近似预算；不能宣称跨 worker/主机共享或完整抗滥用防护。
反向代理后的用户可能共享传输 IP 预算。输入及读取量上限仍是主要工作量边界。

## SMTP

Web 配置 `EMAIL_TIMEOUT = 10` 秒，自定义 SMTP_SSL 后端传入同一 socket 超时；
显式自定义值须为 `(0, 30]` 内有限数值，缺失配置使用 10 秒。证书与主机名验证
保持开启，失败连接被关闭/丢弃，不自动重试或新增线程。

连接、登录、发送超时仍是失败，验证码接口不会声称发送成功。超时按 socket
阻塞操作计，不是整个投递过程的硬截止，也不保证限制系统 DNS 查询时间。
测试只使用模拟 SMTP；上线验收不向真实邮箱发验证码。

## 验证说明

真实测试数据仅创建于隔离 SQLite 的临时 unmanaged 表；生产只读规模预检使用
只读事务和聚合数，不写入测试数据。2026-10-25 预检：单星域最多 1,667 颗行星、
预表共 5,708 行、集市单序列最多 20 点；这些是当时观测，不是永久保证。

防诈隔离回归中，20 与 50 个操作均为固定 6 次 SQL；旧代码 100 条相同操作人
流水曾触发 102 次查询。全球行星预表改为一次有界读取，避免旧相关 MAX 在大
并列输入上的重复工作。不据此推断全站 P95 或统一提速百分比。

新测试接入完整 CI。冻结的发布策略不被放宽；新增 CI 测试标签保守计入构建
指纹（opaque），要求重新验证和发布，而不是擅自刷新服务器策略以允许 no-op。
仍走完整 PR、master CI 和受保护的 Production，结果另记于绑定版本的验收记录。
